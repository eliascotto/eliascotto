# Public projects

Relevant personal projects grouped by programming language.

## Js/Ts

- [Ultrafocus](https://github.com/eliascotto/ultrafocus) A plugin to turn Obsidian into the ultimate platform for focused writing.
- [Replay](https://github.com/eliascotto/obsidian-replay) Obsidian plugin to record your writing, to re-watch and share your writing process.
- [Liture quotes](https://github.com/eliascotto/liture-quotes) A personal book higlights manager for desktop.
- [youtube-subtitles-downloader](https://github.com/eliascotto/youtube-subtitles-downloader) Node library for download subtitles from Youtube.
- [youtube-subtitles-viewer](https://github.com/eliascotto/youtube-subtitles-viewer) A chrome extension to visualize subtitles on YouTube videos.

## Rust

- [Walden](https://github.com/eliascotto/walden): A CLI tool to hard block harmful or addictive websites.
- [fmlisp](https://github.com/eliascotto/fmlisp) An interpreter for a Clojure-like language written in Rust.

## Common Lisp

- [cl-raygui](https://github.com/eliascotto/cl-raygui) Common Lisp bindings for raygui.
- [zed-common-lisp](https://github.com/eliascotto/zed-common-lisp) Common Lisp syntax support for Zed with cl-lsp.
- [cl-guestbook](https://github.com/eliascotto/cl-guestbook-v2) A demo Common Lisp web app.

## Python

- [walden-list](https://github.com/eliascotto/walden-list) Reproducible, categorized domain lists for Walden.
- [export-kobo](https://github.com/eliascotto/export-kobo) A Python tool to export annotations and highlights from a Kobo SQLite file.
- [pyomegle](https://github.com/eliascotto/pyomegle) Python API for Omegle webchat.

## Clojure

- [TryClojure](https://github.com/eliascotto/tryclojure) Clojure live REPL tutorial.
- [Lucifero](https://github.com/eliascotto/lucifero) Simple static website generator written in Clojure.

## CSS

- [shades-of-purple-obsidian](https://github.com/eliascotto/shades-of-purple-obsidian) Shades of Purple theme for Obsidian.

## Elisp

- [accent](https://github.com/eliascotto/accent) Emacs extension for accent characters.
